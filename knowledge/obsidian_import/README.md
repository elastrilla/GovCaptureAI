# Obsidian Import Staging

Use this folder for selected markdown notes copied from the Obsidian LLM wiki.

This is not a full vault sync. It is a curated staging area for GovCaptureAI-safe knowledge.

## What To Copy Here

- Capture process notes
- Proposal response patterns
- Bid/no-bid lessons learned
- Public GovCon terminology
- Demo-safe objection handling
- Reusable technical proposal language
- General cost proposal planning notes
- Sanitized examples with no customer-sensitive data

## What Not To Copy Here

- Credentials or secrets
- Customer names unless approved for demo use
- CUI, FCI-sensitive details, or protected contract data
- Proprietary indirect rates, margin targets, or live pricing
- Private personal notes
- Drafts that include confidential client language

## Suggested Folder Pattern

- `demo-safe/` for notes that can safely support demos
- `proposal-patterns/` for reusable response structures
- `capture-workflow/` for qualification and bid/no-bid guidance
- `pricing-v2/` for future cost proposal concepts
- `source-review/` for notes that still need cleanup before use

## Import Metadata

When copying a note, add or preserve simple front matter when possible:

```yaml
---
title: Example note title
knowledge_type: proposal_pattern
demo_safe: true
source: obsidian
reviewed_by: Enrique
reviewed_date: 2026-07-24
---
```
